Frequently asked questions

A few things to know before using the tool.

Can I download private videos?＋

No. This tool is intended only for publicly accessible content that you have permission to save.

Why is a backend required?＋

A browser-only page cannot reliably retrieve media from third-party platforms because of platform restrictions and browser security rules. A compliant server-side integration is required.

Does this page store my links?＋

This frontend does not send or store your links. A future backend should clearly disclose any data it processes.
